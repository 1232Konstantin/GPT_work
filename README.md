# Manga Offline Translator 0.11

Локальное приложение Windows (PySide6, Pillow, OpenCV). При редактировании нет сетевых запросов и вызовов OCR. Исходное изображение не перезаписывается, итог сохраняется в PNG.

## Основной сценарий

1. Откройте папку или изображение в просмотрщике. Режим «Перевести страницу» открывается **в том же окне**.
2. **Очистка**: нарисуйте одну рамку мышью; фрагмент автоматически скопируется в буфер обмена. Кнопка «Вставить из буфера» размещает плавающий фрагмент.
3. **Очистка — удаление текста**: выберите тип текста и выделите область надписи. Приложение подсветит удаляемые пиксели и нарисует прямоугольники найденных контрастных объектов. Щелчок по зелёной рамке исключает объект (серая рамка). Кнопка «Очистить» изменит **только подтверждённые пиксели**, а затем снимет выделение. Для следующей надписи выделите новую область. Ctrl+Z отменяет очистку. Расширенные настройки восстановления находятся в меню «⋯».
4. **Текст**: протяните мышью независимую рамку, введите перевод и настройте шрифт, размер, цвет, жирный/курсивный/подчёркнутый стиль и выравнивание. Текстовый блок остаётся отдельным объектом до экспорта. Рамка **перемещается за верхнюю границу (или Alt+перетаскиванием внутри)** и изменяется за края и углы. Двойной щелчок возвращает к ранее созданному блоку и его настройкам.
5. **Кисти**: отдельная тёмная панель с инструментами рисования, толщиной (запоминается для каждой кисти), непрозрачностью, палитрой и пипеткой. При наведении пипетка отображает цвет пикселя в кружке над прицелом.
6. **Масштаб**: видимый список «Вписать», 25–400 %, произвольное значение и кнопка «100%». Масштабирование не меняет исходные пиксели.
7. **Сохранить PNG**: сохранение результирующей страницы без потерь. Начальный файл остаётся неизменным.

## Важные сочетания

- Alt+C — режим очистки; Alt+T — текст; Alt+B — кисти.
- Ctrl+C / Ctrl+V / Ctrl+X — копировать / вставить / вырезать; в редакторе текста стандартные сочетания работают с текстом.
- Ctrl+Z / Ctrl+Y — отмена / повтор операции редактора.
- Esc — отменить выделение или плавающую вставку.
- Enter — подтвердить плавающую вставку; Ctrl+S — сохранить PNG.

## Примечания к очистке

Применяется принятый ранее алгоритм контрастной попиксельной маски без OCR. Рамки — это способ подтверждения **объектов**, а не прямоугольники для грубого закрашивания. Тип «Ровный фон» определяет яркость символов относительно границ маленькой рамки. Текст может иметь светлую или тёмную обводку. Сложные текстуры могут потребовать исключения неверно найденного объекта или локальной ретуши; за пределами подтверждённой маски изменение пикселей запрещено.

## Тесты

Алгоритмические тесты: `python -m pytest -q tests`. Проверка Qt-взаимодействия: `python main.py --gui-self-test`. Windows CI проверяет приложение из исходников, упакованный EXE, установку и удаление приложения. UI проверяется также реальным имитированием событий мыши для перемещения и изменения размеров текста.

## Версия 0.9

Три режима правой панели: «Очистка», «Текст», «Кисти». Рамки создаются мышью, отдельные кнопки не нужны. Undo/Redo разделяет команды редактирования текста и изображения.

## Что изменилось в 0.10

- Enter в текстовом редакторе добавляет новую строку; Ctrl+Enter применяет надпись. При смене панели текст также применяется. Сохраняется возможность повторно выбрать надпись.
- История хранит только применённые надписи, завершённые операции очистки и вставки, а также цельные мазки кистей.
- «Кисти»: карандаш (от 1 пикселя), заливка, баллончик, размывайка, восстановление оригинала. Пипетка сохраняет просмотр цвета.
- Вставляемые фрагменты отображаются без принудительной прозрачности.

### Исправления 0.10.0-preview.3

- Очистка снова обнаруживает новые надписи в ранее очищенных или пересекающихся областях после действий с текстом, кистью и Undo/Redo.
- Undo/Redo хранит до 50 операций, изображения в истории сжаты без потери качества.
- Пипетка использует одну и ту же координату и один источник пикселей для предварительного просмотра и выбора цвета.
- Диагностика операций без записи изображений и текста: на Windows `%LOCALAPPDATA%\\MangaOfflineTranslator\\editor.log` (журнал с ротацией).
- Enter продолжает добавлять новую строку, Ctrl+Enter применяет текст.

### Версия 0.11 — очистка и перетаскивание папок

**Поиск символов:** оценка фонового цвета по границам выделения либо по цветам внутри выделения; независимый переключатель «Текст с обводкой» для замкнутых контуров. Результат показывается точной непрозрачной маской (зелёная, чёрная, красная или белая). Исключённые щелчком компоненты — пурпурные; щелчок относится к пикселям найденной маски с небольшим допуском, а не к ограничивающему прямоугольнику.

**Восстановление фона:** по соседним пикселям (Telea), однотонная заливка, горизонтальная и вертикальная интерполяция от соседних пикселей, двумерная и квадратичная аппроксимация; независимый флаг «Усреднить» для коррекции выбросов относительно сеточных проб неповреждённого фона (узлы внутри маски пропускаются). В любом режиме изменяются только выбранные пиксели маски. Настройки сохраняются между запусками.

**Просмотрщик:** папку с изображениями можно перетащить из проводника на изображение или окно просмотрщика. Отдельные файлы и интернет-ссылки не принимаются как папки.

**Совместимость:** Enter вводит новую строку, Ctrl+Enter применяет текст; Undo/Redo до 50 команд; инструменты кистей, вставка фрагментов и просмотрщик сохранены.

### Исправления 0.11.0-preview.2

- Отдельный настоящий карандаш: рисование по пикселям исходного изображения без сглаживания и без уменьшенного Lanczos-предпросмотра во время работы карандашом. Один пиксель толщины соответствует одному пикселю растра.
- Ранее существовавший карандаш сохранён отдельным инструментом «Кисть», толщина каждого инструмента сохраняется независимо.
- Просмотрщик следит за текущей папкой и обновляет список изображений при появлении новых файлов, включая сохранённые редактором PNG. Текущая страница, порядок сортировки и масштаб не сбрасываются.

### Исправления 0.11.0-preview.3 — обнаружение символов

- Короткие названия способов оценки фона: «По границам» (`border`) и «По фону» (`area`). Сохранённые настройки работают без миграции.
- Тёмные и светлые контрастные пиксели, а также пиксели отличающегося цвета независимо включаются в маску; цветным буквам не требуется дополнительный перепад яркости.
- Пороги контраста и цвета учитывают разброс оттенков предполагаемого фона. Символы, частично обрезанные границей выделения, не удаляются из результатов поиска целиком.
- Чекбокс обводки заполняет подходящие замкнутые области, но не произвольные открытые фигуры; небольшие разрывы контуров обрабатываются замыканием.
- Диагностика содержит пороги, количество контрастных/цветовых пикселей и итоговый размер маски; сам текст и изображение не записываются. Проверки включают цветные шрифтовые глифы и слабоконтрастные фигуры.
