# Manga Offline Translator 0.9.0 — единый редактор манги

Локальное приложение Windows (PySide6, Pillow, OpenCV). Исходный файл не перезаписывается. Сохранение в PNG без потерь. OCR и облако при ручном редактировании не используются.

## Три режима правой панели

**Очистка (Alt+C)**. Протяните одну рамку вокруг текста. Фрагмент сразу копируется в системный буфер как **изображение** для Google Translate в браузере. Программа показывает маску контрастных объектов, отдельные объекты можно исключить щелчком. Нажмите «Очистить»; после операции рамка исчезает. Новая рамка автоматически заменяет старую. Кнопка «Вставить из буфера» открывает плавающее изображение: мышью можно его передвинуть/изменить размер, Enter подтверждает, Esc отменяет.

**Ровный фон** — флажок на панели очистки для небольших фрагментов на однородной заливке. Фон оценивается по **четырём границам выделенного прямоугольника**. Программа восстанавливает только пиксели утверждённой маски. Без этого флажка используется принятый алгоритм контрастной сегментации и восстановления градиента/текстуры. Тип надписи выбирается в списке: тёмная, светлая или с обводкой. Дополнительные параметры — в меню «⋯».

**Текст (Alt+T)**. Протяните мышью рамку на странице. Отдельной кнопки создания больше нет. В правой панели задайте шрифт, размер, цвет, жирный/курсивный/подчёркнутый стиль и выравнивание. Рамка перемещается за верхний край (или Alt+перетаскиванием) и растягивается за границы и углы. Другой текстовый блок можно активировать двойным щелчком; **активная рамка только одна**, неактивный текст остаётся видимым. До экспорта все текстовые блоки редактируемые.

**Кисти (Alt+B)**. Независимые инструменты, толщина, непрозрачность, палитра, пипетка с индикатором цвета. Толщина запоминается для каждой кисти; прочие настройки сохраняются между запусками.

## История

Ctrl+Z / Ctrl+Y — **единая хронологическая история**, но независимые данные в каждой команде. Очистка, вставка, вырезание и кисти — растровые команды; ввод, создание, удаление, форматирование, перемещение и изменение размеров текста — текстовые. Отмена очистки **не откатывает несвязанный перевод**. Растровые изменения сохраняются как изменённые фрагменты, а не снимки всего изображения. Настройки интерфейса и сохранение не входят в историю. Последовательный ввод объединяется при короткой паузе или смене режима.

Масштабирование колесом и из списка с пунктом 100% не изменяет пиксели оригинала. Просмотрщик и поиск дубликатов доступны в том же окне.

## Тестирование

Алгоритмические тесты: python -m pytest -q tests. GUI сценарий: python main.py --gui-self-test. Windows Actions проверяет исходники, собранный EXE и установленное приложение.
